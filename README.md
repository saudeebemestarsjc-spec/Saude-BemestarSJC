# Landing page — Evento de Saúde & Bem-Estar

Site estático responsivo, feito em HTML, CSS e JavaScript puro para publicar no GitHub Pages.

## Arquivos
- `index.html` — estrutura e conteúdo da página.
- `style.css` — layout, cores, tipografia e responsividade.
- `script.js` — menu mobile, compartilhamento e cópia do endereço.
- `assets/images/` — cartazes e artes enviados para o projeto.
- `.nojekyll` — evita processamento Jekyll desnecessário.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie **todos os arquivos e pastas** deste ZIP para a raiz do repositório. O `index.html` precisa ficar na raiz publicada.
3. No repositório, abra **Settings → Pages**.
4. Em *Build and deployment*, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`; salve.
6. Aguarde a publicação e abra a URL indicada pelo GitHub Pages.

Não há etapa de build nem dependências para instalar.

## Antes de publicar
- Confirme se a data correta é **17 de outubro** e, se desejar mostrar o ano, acrescente-o depois de confirmar a informação.
- Confirme o endereço e o horário com a organização.
- Confira se todos os cartazes continuam atualizados.
- O botão de compartilhar usa a URL atual da página; funciona melhor depois que o site estiver publicado em HTTPS.
- O mapa abre uma busca do endereço no Google Maps; confira o ponto exato no mapa antes de divulgar.

## Personalizar
Edite os textos diretamente em `index.html` e as cores no início de `style.css`, dentro de `:root`.
